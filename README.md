# Java - Curso Udemy

Repositório criado para armazenar os códigos, exercícios e práticas desenvolvidos durante o curso [Java COMPLETO: Do Zero ao Profissional + Projetos!](https://www.udemy.com/course/fundamentos-de-programacao-com-java/), da Cod3r Cursos Online.

## Sobre

Este repositório acompanha meu estudo de Java, servindo como registro do meu progresso e como material de consulta para os conceitos aprendidos ao longo do curso.

Os códigos aqui presentes são, em sua maioria, exercícios e exemplos desenvolvidos durante as aulas.

## Conteúdos estudados

- Fundamentos e sintaxe do Java
- Variáveis, tipos de dados e operadores
- Estruturas condicionais e de repetição
- Arrays
- Métodos e funções
- Programação Orientada a Objetos
- Tratamento de exceções
- Coleções e Generics
- Lambda e Stream API
- Banco de dados

## Tecnologias

- Java
- Eclipse IDE
- Git
- GitHub

## Objetivo

Consolidar os fundamentos da linguagem Java por meio de prática constante e construir uma base para estudos posteriores de desenvolvimento backend.
